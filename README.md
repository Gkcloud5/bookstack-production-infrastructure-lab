# BookStack Production Infrastructure Lab

A hands-on infrastructure learning project based on the open-source BookStack application.

## Project Goal

The goal is to take BookStack from a source-code repository and progressively build, operate, troubleshoot, secure, monitor, and deploy it as a production-style application.

## Important Principle

This is not simply a Docker project.

The goal is to learn how to take responsibility for running an application:

> Understand how it works, how it fails, how to troubleshoot it, how to secure it, and how to recover it.
